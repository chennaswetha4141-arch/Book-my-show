MOVIE BOOKING APP
=================

How to run:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Enter customer name and mobile number.
4. Select a show time.
5. Select one or more seats.
6. Click Confirm Booking.
7. A successful booking message will appear.

Note:
Browsers normally allow window.close() only for windows/tabs opened by JavaScript.
If index.html is opened manually, the browser may refuse to close the tab.
